# The Grand Archive

A personal anime, manga, and fiction archive built as a single-page static website.

## What is inside

- `index.html` — the website
- `assets/images/` — artwork used throughout the archive
- `media/` — video clips and poster images
- `.nojekyll` — tells GitHub Pages to serve the files directly

## Publish with GitHub Pages

1. Create a new public repository on GitHub, for example `grand-archive`.
2. Upload everything in this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the public Pages URL after deployment.

The site uses relative paths, so the media and assets folders must remain beside `index.html` exactly as they are here.
